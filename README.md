
## Model

`simulator.py` implements a two‑lineage (Victoria, Yamagata), three‑region
(Northern‑Hemisphere temperate, Tropics, Southern‑Hemisphere temperate)
compartmental influenza B model:

- **SIRS dynamics** with waning immunity (mean durations `T_V`, `T_Y`),
  all‑or‑none lineage cross‑immunity (`sigma_VY`, `sigma_YV`), seasonal transmission
  forcing (phase `phi`), and between‑region mixing (`m`). The force of infection
  balances the contacts between regions: a person in region *i* makes a fraction
  `m N_j / N` of their contacts with region *j*, and everyone makes the same total
  number of contacts.
- A **COVID‑19 contact reduction** applied from the April 2020 lockdown,
  with initial magnitude `c_0` and relaxation timescale `tau`.
- A **deterministic** ODE integration (`scipy.solve_ivp`) for the main dynamics,
  plus **stochastic tau‑leaping** ensembles (0.1‑day leaps, starting from rounded
  counts) for the extinction risk of Victoria after Yamagata's extinction and for
  the outbreak probability of hypothetical Yamagata reintroductions.

`simulator_leaky.py` is the same model with leaky instead of all‑or‑none
cross‑immunity (deterministic only), used in the SI section on the all‑or‑none
immunity assumption.

The ten free parameters and their search bounds are listed in Table 1 of the
paper (and in Section 2 of the notebook).

## How to run

Open `reproduce_results.ipynb` (JupyterLab, classic Notebook, or VS Code) and
run the cells top to bottom. Every output is written to the working directory.
Two settings at the top of the notebook (Section 0) control the cost:
`N_CORES`, the number of worker processes, and `NSIMS`, the size of each
stochastic ensemble.

**Runtime notes**

- **Latin hypercube search (Section 2).** The one‑million‑sample search produces
  `search_1M.csv`, which Sections 3 and 4 (Fig. 2) read. Because the file is
  ~200 MB it is not included in this deposit, so Section 2 must be run first to
  reproduce Table 1 and Figs. 2 and S2–S5. The search is *deterministic*
  (`seed=42`), so it reproduces the samples exactly, but takes about 39 hours on
  8 cores. Once `search_1M.csv` exists in this directory the cell skips the
  search; delete the file to force a fresh search.
- **Loops over the filtered samples (Sections 4 and 7).** The deterministic model
  runs once per filtered sample (595 samples) in Section 4 and once more, with
  leaky cross‑immunity, in Section 7, in parallel on `N_CORES` processes. Their
  results are cached in `filtered_outputs.csv` and `leaky_scan.csv`; delete
  these files to recompute them.
- **Stochastic runs (Section 5).** `NSIMS = 100000` reproduces the published
  figures and probabilities, at about 40 minutes per sample for the four best
  fits. Lower `NSIMS` for a quick qualitative check (the figures and
  percentages then differ slightly).
- **Redrawing.** The model figures of Sections 5 and 7 save the data they show
  next to them (`<figure>_plotdata.pkl`); `simulator.redraw_fig3('<figure>.png',
  title=...)` redraws one without rerunning the model.

## Tests

```bash
python -m pytest tests
```

runs, in a few minutes, the tests in `tests/test_model.py`:

- the balanced mixing gives everyone the same number of contacts and balances the contacts between regions;
- without seasonality or lockdown, the coexistence equilibrium the model starts from is stationary (both
  simulators, both leaky modes);
- the best fit reproduces its numbers in the paper (Table S1, Fig. 3);
- runs that stop early return every output, for each reason a run can stop;
- the search records a run whose model fails instead of stopping;
- without cross-immunity, the leaky model is the all-or-none model;
- small stochastic ensembles return the same results as they print. Their exact counts depend on numpy's
  random streams, so this test needs the numpy version in `requirements.txt`.

## Changes from the previous version of this deposit

- The force of infection now balances the contacts between regions (see
  *Model*); the search, the selection, the likelihood and every result were
  rerun with it (3,844 selected and 595 filtered samples).
- The stochastic ensembles start from rounded counts and take 0.1‑day leaps
  (1‑day leaps let the ensemble mean drift below the deterministic solution);
  they also run much faster and store only what the figures use.
- The Northern‑Hemisphere likelihood matches model and data weeks by ISO year
  (`%G`); three data weeks around the new year were previously matched to the
  model's week a year earlier.
- By default the model runs to July 2027, through the 2026–27 season.
- A run whose model fails is recorded (`success=False`) instead of stopping the search; `model()`
  returns the results of its stochastic ensembles as well as printing them; tests (`tests/`). The
  results are unchanged.
- New analyses: the four best fits side by side (Table S1; Figs. S13–S23),
  the reporting rates (Figs. S10–S11), the timing of Victoria's minimum
  (Fig. S9), leaky cross‑immunity, and the influenza B infections per year with
  and without Yamagata on the periodic attractors.

## Data provenance

The `FluNet_*.csv` files are weekly influenza B report counts (B/Victoria,
B/Yamagata, and B with lineage not determined) downloaded from the WHO FluNet
database (<https://www.who.int/tools/flunet>), aggregated by region and
restricted to 2015‑10‑01 through 2025‑09‑30.

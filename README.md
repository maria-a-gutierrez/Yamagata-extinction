# Reproduction code: post-pandemic dynamics of influenza B (Victoria & Yamagata)

This repository contains the model and analysis code needed to reproduce the
results and figures of the accompanying paper on the COVID‑19‑era extinction of
the influenza B/Yamagata lineage and the post‑pandemic reemergence of B/Victoria.

> **Citation / DOI:** _Add the paper citation and the Zenodo DOI here once minted._
> **License:** MIT — see [License](#license) below.

## Model

`simulator.py` implements a two‑lineage (Victoria, Yamagata), three‑region
(Northern‑Hemisphere temperate, Tropics, Southern‑Hemisphere temperate)
compartmental influenza B model:

- **SIRS dynamics** with waning immunity (mean durations `T_V`, `T_Y`),
  lineage cross‑immunity (`sigma_VY`, `sigma_YV`), seasonal transmission
  forcing (amplitude/phase `phi`), and between‑region mixing (`m`).
- A **COVID‑19 contact reduction** applied from the April 2020 lockdown,
  with initial magnitude `c_0` and relaxation timescale `tau`.
- A **deterministic** ODE integration (`scipy.solve_ivp`) for the main dynamics,
  plus a **stochastic tau‑leaping** ensemble used to assess lineage extinction
  during the lockdowns and the fade‑out probability of hypothetical Yamagata
  reintroductions.

The ten free parameters and their search bounds are listed in Table 1 of the
paper (and at the top of Section 2 of the notebook).

## How to run

Open `reproduce_results.ipynb` (JupyterLab, classic Notebook, or VS Code) and
run the cells top to bottom. Every figure is written to the working directory.

**Important runtime notes**

- **Latin Hypercube search (Section 2).** The one‑million‑sample search produces
  `search_1M.csv`, which every later section reads. Because the file is ~200 MB it
  is not included in this deposit, so Section 2 must be run before anything else.
  The search is *deterministic* (`seed=42`) — it reproduces the published samples
  exactly — but takes several hours on 8 cores. Once `search_1M.csv` exists in this
  directory the cell detects it and skips the search on later runs; delete the file
  to force a fresh search.
- **NH best fit (Section 4).** The stochastic trajectory uses
  `nsims = nsims2 = 100000`, which reproduces the published figure but is slow.
  Lower these values for a quick qualitative check.
- **Reintroduction / scatter loops (Section 5).** These run the deterministic
  model once per filtered sample (559 samples), several times over, and can take
  a while.

## Data provenance

The `FluNet_*.csv` files are weekly influenza B report counts (B/Victoria,
B/Yamagata, and B with lineage not determined) downloaded from the WHO FluNet
database (<https://www.who.int/tools/flunet>), aggregated by region and
restricted to 2015‑10‑01 through 2025‑09‑30.
